## 📊 역대 1등 당첨 데이터의 6대 핵심 통계 필터

본 생성기는 무의미한 단순 무작위 번호가 아닌, 역대 1등 당첨 조합의 80% 이상에서 공통적으로 검증된 통계적 기준을 필터링합니다:

1. **총합 구간 (Sum Range)**: 6개 번호의 합계가 **100 ~ 175** 사이 (정규분포 기준 최다 빈도 구간)
2. **홀짝 비율 (Odd:Even)**: **3:3, 4:2, 2:4** (전체 당첨의 약 80%)
3. **고저 비율 (Low:High)**: 1~22(저) vs 23~45(고) 비율이 **3:3, 4:2, 2:4**
4. **산술적 복잡도 (AC값)**: **7 이상** (단순 등차수열이나 특정 패턴 배제, 역대 82% 이상)
5. **연속 번호 제한 (Consecutive Numbers)**: 3연속 이상 번호 배제 (0쌍 또는 1쌍의 연번 권장)
6. **끝자리 중복 제한 (Same Last Digit)**: 동일한 1의 자리 번호가 3개 이상 중복되는 경우 배제
7. **구간 분산도 (Section Spread)**: 10단위 5개 구간 중 최소 3개 이상 분산

## 🎯 5가지 생성 전략 (게임별 포트폴리오)

* **Game A: 황금 통계 모델 (Golden Ratio Filter)**
  - 역대 1등 당첨 통계 필터(총합, 홀짝, 고저, AC값, 연번 등)를 100% 통과하는 최적 균형 조합
* **Game B: 역대 최다 출현 핫넘버 (Hot Numbers Priority)**
  - 27, 13, 34, 12, 33 등 역대 누적 출현 빈도가 높은 번호들에 통계적 가중치를 부여
* **Game C: 평균 회귀 콜드넘버 (Cold Numbers Reversion)**
  - 9, 22, 41, 23, 29 등 상대적으로 적게 출현하여 장기적으로 평균 회귀 가능성이 있는 번호 반영
* **Game D: 하이브리드 앙상블 (Hybrid Ensemble)**
  - Hot 3개 + Neutral 2개 + Cold 1개를 결합한 이상적인 위험 분산 포트폴리오
* **Game E: 종합 밸런스 추천 (Comprehensive Balance)**
  - 높은 AC값과 균형 잡힌 구간 분산도를 지닌 추천 조합

## 🚀 실행 방법

### 1) 1회 즉시 실행 (5게임 슬립 생성)
```bash
python main.py --once
```

### 2) 대화형 메뉴 실행 (고정수 및 제외수 지정 가능)
```bash
python main.py
```
- 고정수: 반드시 포함하고 싶은 번호 지정 (예: `7, 27`)
- 제외수: 절대 나오지 않기를 바라는 번호 지정 (예: `9, 41`)
