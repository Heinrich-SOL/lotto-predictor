# 🎱 로또 6/45 역대 빅데이터 분석 및 번호 예측 생성기

대한민국 동행복권 로또 6/45의 **제1회부터 최신 제1248회까지의 누적 당첨 전수 데이터**를 바탕으로, **역대 1등 당첨번호와 완전히 겹치는 조합(6개 일치)을 100% 원천 배제**하고 역대 1등 당첨 패턴의 통계적 황금 비율을 만족하는 최적의 번호 조합을 추출해 주는 프로그램입니다.

## 📊 역대 1등 당첨 데이터의 7대 핵심 통계 & 중복 배제 필터

본 생성기는 무의미한 단순 무작위 번호가 아닌, 역대 1등 당첨 조합의 80% 이상에서 공통적으로 검증된 통계적 기준을 필터링합니다:

1. **[신규 핵심] 역대 1등 당첨번호 중복 배제**: 제1회부터 최신 회차까지 **역대 1등으로 이미 출현한 6개 번호 조합과 100% 일치하는 조합 원천 배제** (슬립 내 5개 게임 간 상호 중복도 방지)
2. **총합 구간 (Sum Range)**: 6개 번호의 합계가 **100 ~ 175** 사이 (정규분포 기준 최다 빈도 구간)
3. **홀짝 비율 (Odd:Even)**: **3:3, 4:2, 2:4** (전체 당첨의 약 80%)
4. **고저 비율 (Low:High)**: 1~22(저) vs 23~45(고) 비율이 **3:3, 4:2, 2:4**
5. **산술적 복잡도 (AC값)**: **7 이상** (단순 등차수열이나 특정 패턴 배제, 역대 82% 이상)
6. **연속 번호 제한 (Consecutive Numbers)**: 3연속 이상 번호 배제 (0쌍 또는 1쌍의 연번 권장)
7. **끝자리 중복 제한 (Same Last Digit)**: 동일한 1의 자리 번호가 3개 이상 중복되는 경우 배제
8. **구간 분산도 (Section Spread)**: 10단위 5개 구간 중 최소 3개 이상 분산

## 🎯 5가지 생성 전략 (게임별 포트폴리오)

* **Game A: 황금 통계 모델 (Golden Ratio Filter)**
  - 역대 1등 당첨 통계 필터(총합, 홀짝, 고저, AC값, 연번 등)와 역대 1등 중복 배제를 100% 통과하는 최적 균형 조합
* **Game B: 역대 최다 출현 핫넘버 (Hot Numbers Priority)**
  - 27, 13, 34, 12, 33 등 역대 누적 출현 빈도가 높은 번호들에 가중치를 부여하며 역대 중복 조합 제외
* **Game C: 평균 회귀 콜드넘버 (Cold Numbers Reversion)**
  - 9, 22, 41, 23, 29 등 상대적으로 적게 출현하여 장기적으로 평균 회귀 가능성이 있는 번호 반영
* **Game D: 하이브리드 앙상블 (Hybrid Ensemble)**
  - Hot 3개 + Neutral 2개 + Cold 1개를 결합한 이상적인 위험 분산 포트폴리오
* **Game E: 종합 밸런스 추천 (Comprehensive Balance)**
  - 높은 AC값과 균형 잡힌 구간 분산도를 지닌 추천 조합

## 🚀 실행 방법

### 1) Python CLI 실행

#### 1회 즉시 실행 (5게임 슬립 생성)
```bash
python main.py --once
```

#### 대화형 메뉴 실행
```bash
python main.py
```
- **1. 새 5게임 번호 다시 뽑기**: 역대 1등 미출현 조합으로 즉시 5게임 생성
- **2. 최고 확률 순위 기준 변경**: TOP 10~45위 범위 조절
- **3. 고정수/제외수 지정 생성**: 포함하거나 제외할 번호 지정
- **4. 1~45번 전체 출현율(%) 조회**: 누적 1248회 순위표 확인
- **5. 내 번호 역대 당첨 이력 및 중복 검사**: 내가 가진 6개 번호가 역대 1등과 겹치는지, 역대 최고 몇 개나 맞았는지 정밀 조회
- **6. 최신 회차 자동 동기화**: 신규 공식 API를 통해 새로운 추첨 결과 원클릭 업데이트

### 2) 웹 브라우저 & 스마트폰 PWA 실행
- `index.html` 파일을 브라우저(Chrome, Safari 등)로 열면 직관적인 모바일 친화 UI로 로또 번호를 생성할 수 있습니다.
- 상단 **"역대 당첨번호 중복 배제 필터"** 토글을 통해 중복 차단 여부를 켜고 끌 수 있습니다.
- 각 게임 카드 하단에 **`🛡️ 역대 1등 미출현 (역대 최대 N개 일치: 제M회)`** 뱃지가 실시간으로 표기됩니다.
